# Community gallery — how to add your build

> 🇪🇸 **¿Prefieres leer esto en español?** → [README.es.md](README.es.md)

Thanks for wanting to share your BFS9000 build! Here's how:

1. Create a folder with your name (or handle) under `media/kbpic/`:

   ```
   media/kbpic/<your-name>/
   ```

2. Add your photos inside it (JPG or PNG, ideally a few MB or less each). Name them however you like, for example `01.jpg`, `02.jpg`...

3. Add a row for your build to the **Community builds** table in [`README.md`](../../README.md) (or [`README.es.md`](../../README.es.md), if you'd rather write your caption in Spanish), using this template:

   ```markdown
   | <img src="media/kbpic/<your-name>/01.jpg" width="220"> | **Your Name** — [GitHub](https://github.com/your-user) |
   ```

   Replace the folder name, image path, your name and (optionally) a link to your GitHub or socials. The link is optional — feel free to drop it if you'd rather not include one.

4. Open a pull request with both the new photos and the README change.

That's it — thanks for contributing!
